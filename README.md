# Arbitrage Calculator

A professional web application for finding arbitrage opportunities in sports betting. The project is served with an Express backend and a modern frontend that allows filtering and real-time calculations.

## Live Demo

A deployed version of this project is available on [Render](https://trixialap.onrender.com/).

## Local Setup

```bash
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Deploying to Render

1. Create a new Web Service on Render and link your GitHub repository.
2. Set the **Build Command** to `npm install`.
3. Set the **Start Command** to `npm start`.
4. Make sure the environment uses **Node.js 18** or newer.
